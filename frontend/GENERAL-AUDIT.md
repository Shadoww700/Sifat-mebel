# Sifat Mebel — проверка frontend

21 октября 2026. Отдельная проверка поведения после пяти этапов оформления; результаты предыдущих этапов находятся в `DESIGN-REVIEW.md`.

## Найдено и исправлено

Ошибки сначала воспроизведены регрессионными тестами, затем исправлены:

- `src/components/store/catalog-browser.tsx`: кнопка восстановления пустого каталога сохраняла неверную категорию из исходного URL. Теперь общий каталог сбрасывает её; отдельная страница категории сохраняет своё ограничение.
- `src/lib/api/client.ts`: успешный HTTP-ответ с невалидным JSON считался успешной операцией. Теперь возвращается `ApiError` со статусом 502; корректный DELETE 204 остаётся успешным.
- `src/lib/account/api.ts`: зацикленная пагинация адресов молча возвращала частичный список, структура ответа и путь следующей страницы не проверялись. Теперь такие ответы вызывают явную ошибку, запросы остаются в локальном proxy.
- `src/app/api/backend/[...path]/route.ts`: HTML с HTTP 200 превращался в успешный ответ proxy. Теперь это 502, включая повторный запрос после обновления JWT.
- В том же frontend proxy: временный сбой обновления JWT очищал сессию. Теперь сервисная ошибка сохраняет cookies; действительно отклонённый refresh (400/401) по-прежнему очищает их. Неполный ответ login/refresh не записывает некорректные токены.
- В том же proxy: выход после обновления access не очищал cookies. Теперь очищает; если backend возвращает ротированный refresh, logout использует именно новый токен. Если повторный бизнес-запрос теряет соединение после ротации, новые cookies сохраняются, чтобы не потерять уже обновлённую сессию.

## Границы проверки

API-сценарии выполняются на изолированных HTTP-стендах по существующим контрактам Django; это не проверка доступности и данных живого production API. Полный набор включает серверные фильтры/пагинацию/фотографии, OUT_OF_STOCK, избранное, защиту админки и мобильные экраны. Используется Chrome/Playwright; реальные Safari/Firefox, устройства, нагрузка и полный аудит доступности не проверялись. Отсутствие абсолютно всех ошибок не гарантируется.

Backend, миграции, БД, секреты, `.env` и визуальный дизайн не менялись. SHA-256 Login/Register, auth layout и globals.css совпадают с исходными значениями. Предыдущие изменения оформления и пользовательские изменения в рабочем дереве сохранены. Commit/push не выполнялись.
