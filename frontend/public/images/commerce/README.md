# Каталожные изображения

Четыре изображения сгенерированы встроенным инструментом imagegen как иллюстрации **демонстрационной**, а не реальной товарной коллекции. Это не фотографии продукции продавца. Без сетевых зависимостей на клиенте.

- Режим: built-in image generation; новая генерация, без reference images.
- Экспорт: WebP, 1448 × 1086 px; конвертация формата через Sharp, без ретуши.
- Существующий `/images/sifat-auth-interior.png` не изменялся. В галерее он отдельно подписан как иллюстрация атмосферы, не как дополнительный ракурс товара.
- Для реальных товаров адаптер использует только изображения Django, не подставляет эти демоизображения.
