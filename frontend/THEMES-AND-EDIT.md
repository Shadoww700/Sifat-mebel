# Коллекция: изменение товара и два режима оформления

Обновление 12 октября 2026. Изменения только frontend; backend, БД, миграции, .env, Login/Register и auth layout не редактировались.

## Изменение из коллекции

- В общей ProductCard и на странице товара добавлен `ProductEditLink` — «Изменить». Он ведёт на существующую `/admin/products/{id}`, без создания новых Django endpoints.
- Видимость проверяет `useVerifiedAdmin`: общая сессия `/auth/me`, строго ADMIN, успешный OPTIONS существующего защищённого журнала. Гости, USER, MANAGER, неизвестные роли и ошибки проверки не получают кнопку.
- Админский guard повторно проверяет сессию при входе в карточку и перед сохранением. Реальные права операций по-прежнему проверяет Django. Скрытая кнопка не заявляется заменой серверной авторизации.
- Источники сравниваются до создания ссылки: нельзя использовать числовой ID demo-товара для изменения API-товара с таким же ID или наоборот. При несогласованных источниках ADMIN получает пояснение, а не опасную ссылку.
- В Demo изменения остаются в отдельном учебном адаптере и не публикуются в покупательский fixture-каталог. Для настоящих изменений витрина и админка должны использовать API.

## День / вечер

- Дневной режим — исходный cream/walnut дизайн, по умолчанию.
- Вечерний режим — мягкий графит, тёплый светлый текст, шалфейные, глиняные, сливовые и оливковые карточки. Акцент #00BDC9 сохранён. Нет чисто чёрного полотна, градиентов или замены фотографий.
- Переключатель солнце/луна находится в шапке витрины и управления. На телефоне вход в админку остаётся в мобильном меню, чтобы дополнительные иконки не переполняли шапку.
- Предпочтение хранится в несекретной first-party cookie `sifat-theme`, год, SameSite=Lax, Secure на HTTPS. SSR читает только day/evening и сразу отдаёт выбранную тему; выбор сохраняется при перезагрузке и переходах между витриной и админкой.
- ThemeSurface ограничивает CSS внутри `.store[data-theme]`. Авторизация не получает ни тему, ни переключатель. Корневые auth-стили не менялись.
- CSS-токены централизованы в `styles/theme.css` поверх существующей дневной системы. Нативные поля используют соответствующий color-scheme; фокус остаётся cyan, основные интерактивные поверхности имеют контрастный текст.
- minimalist-ui использован для сдержанной композиции, типографики и приглушённых цветных поверхностей, с сохранением установленной идентичности.

## Проверки

- ESLint, TypeScript, production build — успешно.
- Playwright — 55/55. Проверены запрет редактирования USER/MANAGER/неизвестной роли/ADMIN с отказом backend, открытие правильного товара для ADMIN, persistence темы в SSR, reload и переход в админку, изоляция auth.
- Две темы: дневная — существующая матрица 320–1920 px (витрина до 2560); вечерняя — каталог/PDP/админка/карточка управления на 320, 375, 390, 430, 768, 1280, 1920 px, без горизонтального overflow.
